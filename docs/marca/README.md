# Marca PURSEC — logo (26 oct 2026)

El logo es el nombre PURSEC en cursiva gruesa, con la serpiente formando la S. Sin fondo, sin eslogan ni emblema.

Colores: **negro `#050505`**, **blanco `#FFFFFF`** y **rojo `#C1121F`**. El lila ya no forma parte de la marca.

- `pursec-wordmark.svg` — vector, un solo color (`currentColor`): se tiñe con CSS o en el editor.
- `logo-pursec-blanco.png` — blanco, fondo transparente (para fondos oscuros).
- `logo-pursec-rojo.png` — rojo `#C1121F`, fondo transparente (para fondos claros).

En la web: `public/img/brand/pursec-white.svg` (cabecera y portada), `pursec-red.svg` (pie), `og.jpg` (al compartir el enlace), `public/favicon.svg`, `public/img/favicon-32.png`, `public/img/favicon-512.png` y `public/apple-touch-icon.png` (la "p" en blanco sobre rojo).

Origen: imagen generada con Kling (`kling_20261024_Creation_Minimal_st_4888_0.png`), recortada solo con el nombre (sin fondo, sin marca de agua y sin ™) y vectorizada.
